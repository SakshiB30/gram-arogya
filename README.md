ASHA-Offline-First Rural Healthcare Management System

ASHA is a digital healthcare management platform designed to support ASHA workers, ANMs, and administrators in managing rural healthcare activities efficiently.

The system helps manage beneficiaries, field visits, health records, medicines, notifications, and healthcare activities through a centralized platform.

Its key focus is enabling ASHA workers to continue field work even without internet connectivity.

🎯 Problem
Rural healthcare workers often face:

Poor or unstable internet connectivity
Paper-based healthcare records
Difficulty accessing beneficiary information
Difficulty managing field visits and follow-ups
Limited coordination between healthcare workers
Challenges in recording data during field work

💡 Solution

ASHA provides an offline-first healthcare management system that allows healthcare workers to manage rural healthcare activities digitally.

The platform provides:

Beneficiary Management
Field Visit Management
Health Records
Medicine Management
Notifications
Role-Based Dashboards
ASHA Offline Field Visits
Offline Data Synchronization

When internet connectivity is unavailable, ASHA workers can continue recording field information locally and synchronize it with the central system when the connection is restored.

🛠️ Technology
Frontend: React, Redux Toolkit, React Router, Axios, Tailwind CSS

Backend: Java, Spring Boot, Spring Security, JWT

Database: MongoDB

Offline Storage: IndexedDB

🌍 Impact

ASHA aims to:

Reduce dependency on paper-based records
Support healthcare workers in low-connectivity areas
Improve beneficiary data management
Simplify field visit tracking
Improve coordination between healthcare workers
Support continuous rural healthcare operations
